## Founder-led discovery questions

- What invoice/document problem still takes manual work after your current Peppol/accounting setup?
- How often does it happen in a typical week/month?
- Is the source usually PDF, scan, malformed UBL/XML, or an accounting-system export?
- What do you do today to identify the exact field/rule causing the problem?
- What happens after the fix: re-upload, revalidate, manual entry, email to the client, or escalation to software support?
- Would a bulk diagnostic report for client documents save measurable time? If yes, how many documents at a time?
- What evidence would you need before trusting an automated fix/conversion?
- Which workflow would justify paying for a dedicated tool rather than using the existing accounting/Peppol platform?
